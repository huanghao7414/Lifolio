# Lifolio · 量化人生簿

> **Your life, quantified.**  
> 量化你的生活，看见你的价值。

---

## 产品定位

Lifolio 是一款以 AI 为核心引擎的个人生活资产管理 app。它不只是记账工具——它是你的私人财务智能体（Personal Finance Agent），持续感知你的消费行为、物品价值与生活质量，并主动给出洞察与建议。

用户无需手动分类、无需填写表单。只需用自然语言告诉 Lifolio 发生了什么，AI 完成其余所有事情。

---

## AI 能力层（贯穿全局）

Lifolio 的 AI 不是功能点，而是底层基础设施，渗透进每一个交互环节：

| AI 能力 | 说明 |
|---------|------|
| **自然语言记账** | 说一句话即可完成记账，AI 自动识别金额、分类、时间、物品属性 |
| **多模态输入** | 支持语音、文字、拍照（小票/商品）三种输入方式，AI 统一解析 |
| **物品智能识别** | 拍照即可录入物品，AI 自动补全品牌、型号、市场估值 |
| **折旧智能计算** | 基于物品类型和使用频率，AI 动态估算当前价值与持有建议 |
| **消费洞察生成** | 定期主动推送 AI 生成的消费报告，语气像朋友、不像账单 |
| **价值评分系统** | AI 综合消费结构、物品效用、储蓄率，给出"生活价值健康度"评分 |
| **主动提醒** | AI 感知异常消费、物品闲置过久、预算超支，主动发出提醒 |

## UI 设计规范

- **风格**：Apple HIG，简洁克制，信息密度低，AI 内容用特殊卡片样式区分（如渐变边框、微发光效果）
- **配色**：主色调白/黑，强调色桔红色（`#FF4500` 附近）用于主要 CTA 按钮；AI 生成内容用淡暖色背景区分
- **字体**：SF Pro 系列，层次分明
- **AI 感知设计**：AI 正在思考时显示流式动画（类似 ChatGPT 打字效果）；AI 建议卡片带有"✦ AI 洞察"标签

## 页面结构（4 Tab + 1 AI 核心入口）

### 1. 首页（Home）
- **上层 — 智能总览卡片**：本月净支出、总资产估值、AI 生成的一句话本月总结
- **中层 — 账单流**：交易记录自动分类，AI 标注异常消费，支持左滑编辑
- **下层 — 智能 Tag**：AI 自动生成常用标签，也可手动添加，点击快速筛选

### 2. 物品（Items）
- 网格展示所有物品，显示封面图、名称、AI 估算的当前价值与"值得指数"
- **物品详情页**：
  - 购买价格、日期、使用时长/次数
  - AI 动态折旧曲线（购买价 → 当前估值，标注折旧拐点）
  - 每次使用成本 = 购买价 ÷ 累计使用次数
  - **AI 持有建议**：根据使用频率与市场行情，给出"继续持有 / 出售 / 闲置预警"

### 3. 价值（Value）
- **AI 生活报告**：以对话式卡片呈现，AI 像朋友一样回顾你这周/月的消费与资产变化
- **资产时间线**：净资产趋势图，AI 标注关键转折点并附上解读
- **生活价值评分**：AI 综合多维度数据给出 0–100 分评分，并给出提升建议
- **对比洞察**：AI 对比你的消费结构与上月/同类人群，发现隐藏的消费模式

### 4. 设置（Settings）
- 货币单位、预算上限、AI 推送频率
- AI 个性化偏好（语气：专业 / 轻松 / 严格）
- 数据导出（CSV / JSON）、iCloud 同步
- 隐私设置：AI 数据处理范围说明

### AI 核心入口（底部居中，常驻悬浮按钮）

点击唤起全屏 AI 对话面板，这是 Lifolio 的核心交互入口：

- **自然语言记账**：「今天和朋友吃饭花了 230，AA 了」→ AI 自动拆分、分类、记录
- **拍照识别**：拍小票 → 自动解析所有条目；拍商品 → 自动录入物品库
- **主动提问**：「我这个月花最多的是什么？」「我的 AirPods 还值多少钱？」
- **AI 主动发起**：达到预算阈值或发现消费异常时，AI 主动推送对话卡片

## 核心数据流

```
用户输入（语音/文字/图片）
    ↓
AI 解析引擎（意图识别 → 实体抽取 → 分类）
    ↓
写入账单库 / 物品库
    ↓
AI 持续分析（折旧计算 / 消费模式学习 / 价值评分更新）
    ↓
主动推送洞察 & 建议
```
