# Lifolio · 双端统一设计系统 v2.0

> Your life, quantified. — 量化你的生活，看见你的价值。
>
> 本规范同时服务于 `apps/web`（Next.js + Tailwind）与 `apps/mobile`（Expo / React Native），
> 一套 Token 两处消费，保证同一份数据在手机与桌面上的观感、节奏、语义完全一致。

| 项目 | 内容 |
|------|------|
| 设计基线 | Apple HIG · 克制、低信息密度、内容优先 |
| 品牌强调 | 桔红 `#FF4500`（图形/大号数字）→ `#D63600`（按钮/小字，AA 达标） |
| 覆盖平台 | iOS/Android（390pt 基准）、Web 桌面（1280px 基准） |
| 无障碍 | WCAG 2.1 AA，正文对比度 ≥ 4.5:1，触控目标 ≥ 44×44 |
| 交付物 | 本文档 + `prototype/index.html`（可交互高保真原型） |

---

## 1. 设计原则

| 原则 | 含义 | 落地判据 |
|------|------|----------|
| **一眼看懂，一秒记完** | 记账是高频低注意力行为，主路径必须无表单、无分类选择 | 从打开 App 到完成一次记账 ≤ 3 次交互 |
| **数字有语气，AI 有边界** | 金额用等宽数字对齐；AI 生成内容必须有视觉容器与「✦ AI」标记，永不与确定性数据混排 | 任何 AI 文本都出现在 `--accent-wash` 底 + 标签的卡片内 |
| **克制用色，语义优先** | 桔红只出现在「行动」与「需要你注意」处；中性色承担 90% 界面 | 单屏桔红面积 ≤ 8% |
| **渐进披露** | 首页给结论，二级页给过程，三级页给明细 | 首页不出现超过 1 个图表 |

## 2. 设计令牌（Design Tokens）

### 2.1 颜色

#### 中性色（承载 90% 界面）

| Token | 值 | 用途 | 白底对比度 |
|-------|-----|------|-----------|
| `--ink-1` | `#1D1D1F` | 主文字、金额 | **16.1:1** ✅ AAA |
| `--ink-2` | `#6E6E73` | 次级文字、说明 | **5.07:1** ✅ AA |
| `--ink-3` | `#A1A1A6` | 图标描边、占位符 | 2.57:1 ⚠️ 仅非文字 |
| `--line` | `#E5E5EA` | 分隔线、卡片描边 | — |
| `--track` | `#F0F0F2` | 进度轨道、骨架屏 | — |
| `--surface` | `#FFFFFF` | 卡片、栏底 | — |
| `--canvas` | `#F5F5F7` | 页面底色 | — |

> **⚠️ 相对旧版的修正**：旧版次级文字用 `#86868B`，白底对比度仅 **3.62:1**，未达 AA 正文标准。
> 已统一替换为 `#6E6E73`（5.07:1）。图注的 `#8E8E93`（3.26:1）同样替换。

#### 品牌色

| Token | 值 | 用途 | 对比度 |
|-------|-----|------|--------|
| `--accent` | `#FF4500` | 图形填充、图表柱、Tab 选中底、≥24px 大号数字 | 白底 **3.44:1** ✅ 仅限大字号 / 非文本 |
| `--accent-strong` | `#D63600` | **主按钮底色**、小号强调文字 | 白底 **4.79:1** ✅ AA；白字压其上 **4.79:1** ✅ |
| `--accent-text` | `#C03400` | 强调文字（链接、AI 标签） | 白底 **5.63:1** ✅ AA |
| `--accent-soft` | `#FFE8DD` | Chip / 徽标底 | 配 `--accent-text` **4.78:1** ✅ |
| `--accent-wash` | `#FFF3E8` | AI 卡片底、每次使用成本条 | 配 `#7A4E2E` **6.51:1** ✅ |

> **关键决策**：`#FF4500` 直接承载正文小字是**不合规**的（3.44:1）。
> 因此拆出三档：品牌原色用于**图形与大号数字**（保留视觉资产），
> `#D63600` 用于**可点击填充**，`#C03400` 用于**文字**。三者色相差极小，肉眼统一。

#### 语义色

| 语义 | 文字/主色 | 浅底 | 说明 |
|------|-----------|------|------|
| 成功 · 正向 | `#1E7A34` (5.40:1) | `#E6F4EA` | 储蓄率达标、建议继续持有 |
| 提醒 · 注意 | `#B25E00` (4.63:1) | `#FFF1E0` | 接近预算、低频使用 |
| 预警 · 异常 | `#D63600` (4.79:1) | `#FFE8DD` | 超支、AI 标注异常消费 |
| 信息 | `#0B6BCB` (4.86:1) | `#E8F2FD` | 同步状态、说明链接 |

> **色彩语义约定**：本产品是个人生活账本，**不涉及证券行情**，
> 因此「健康/达标」统一用**绿色**（生活语义），「超支/预警」用**橙红**。
> 支出金额本身用中性 `--ink-1`，不用红色制造焦虑。
> 📌 若未来接入基金/股票模块，该模块内必须切换为**涨红跌绿**（中国惯例），并在模块入口显式提示。

#### AI 深色专注面

| Token | 值 | 说明 |
|-------|-----|------|
| `--ai-canvas` | `#0D0D0F` | AI 面板底色 |
| `--ai-surface` | `#1A1A1C` | AI 气泡 / 输入栏 |
| `--ai-elevated` | `#262629` | 用户气泡 |
| `--ai-text` | `#F5F5F7` | 面板主文字（16.0:1） |
| `--ai-sub` | `#A1A1A6` | 面板次级文字（7.59:1） |

**双形态规则**：
- **内嵌 AI 洞察**（首页/详情页/价值页）→ 浅色 `--accent-wash` 卡片，融于页面
- **全屏 AI 对话**（移动端）/ **右侧 AI 抽屉**（桌面端）→ 深色专注面，进 AI 模式即切换

### 2.3 间距（4pt 栅格）

```
--space-1  4px     --space-5  20px    --space-9   40px
--space-2  8px     --space-6  24px    --space-10  48px
--space-3  12px    --space-7  32px    --space-11  64px
--space-4  16px    --space-8  32px
```

**节奏约定**：元素内 8–12px · 卡片内边距 16–20px · 卡片间距 12px · 区块间距 24px · 页面边距 20px（移动）/ 32px（桌面）。

### 2.4 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--r-sm` | 8px | Chip、徽标、进度条 |
| `--r-md` | 12px | 按钮、输入框、内嵌块 |
| `--r-lg` | 16px | 列表容器、小卡片 |
| `--r-xl` | 20px | 标准卡片 |
| `--r-sheet` | 28px | 底部弹层、桌面抽屉 |
| `--r-full` | 999px | 药丸按钮、标签栏 |

### 2.5 阴影 / 层级

| Token | 值 |
|-------|-----|
| `--e-1` | `0 1px 2px rgba(0,0,0,.04), 0 1px 3px rgba(0,0,0,.03)` |
| `--e-2` | `0 4px 12px rgba(0,0,0,.05), 0 1px 3px rgba(0,0,0,.04)` |
| `--e-3` | `0 12px 32px rgba(0,0,0,.08), 0 2px 8px rgba(0,0,0,.04)` |
| `--focus` | `0 0 0 3px rgba(255,69,0,.28)` |

**使用纪律**：同一屏最多 1 个元素用 `--e-3`；卡片默认 `--e-1`，悬停 `--e-2`。

### 2.6 动效

| Token | 值 | 场景 |
|-------|-----|------|
| `--t-fast` | 120ms `cubic-bezier(.2,0,1,1)` | 按压反馈、Switch |
| `--t-base` | 200ms `cubic-bezier(.2,0,1,1)` | 页面淡入、悬停 |
| `--t-slow` | 320ms `cubic-bezier(.2,0,1,1)` | 弹层、AI 抽屉 |

AI 流式文字：逐字 18ms/字，光标 `opacity` 1.2s 循环。
**必须**包裹 `@media (prefers-reduced-motion: reduce)` 降级为无动画。

| 区域 | 规格 |
|------|------|
| 状态栏 | 54pt（含灵动岛安全区） |

| 侧边栏 | 固定 248px，可折叠为 72px 图标态 |

| 顶栏 | 64px，含搜索 / 时间范围 / 主 CTA |

### 3.3 响应式断点

```
< 768px    移动端单列，底部标签栏

```

## 4. 组件库

### 4.1 按钮

| 变体 | 底色 | 文字 | 用途 |
|------|------|------|------|
| Primary | `--accent-strong` | `#FFF` 15/600 | 主行动：确认记录、保存 |
| Secondary | `--surface` + `1px --line` | `--ink-1` | 次要行动：取消、稍后 |
| Tertiary | 透明 | `--accent-text` | 文字链：查看全部 |
| Ghost/危险 | 透明 | `#D63600` | 删除、停用 |

尺寸：`h 44 / 36 / 30`，圆角 12 / 10 / 8，水平内边距 20 / 16 / 12。
状态：默认 → 悬停（亮度 −6%）→ 按压（`scale(.97)`）→ 聚焦（`--focus` 环）→ 禁用（`opacity .4`，`pointer-events:none`）。

> 触控目标不足 44 时，用透明 `padding` 或 `min-height` 补足，**不缩小视觉尺寸**。

### 4.2 输入与 AI 输入栏

- 高 44，圆角 12，底 `--surface`，描边 `1px --line`
- 聚焦：描边转 `--accent`，外扩 `--focus` 环
- 错误：描边 `#D63600` + 下方 12px 说明文字（**图标 + 文字双通道**，不靠颜色单独表达）
- AI 输入栏：深色面时底 `--ai-surface`；左侧相机、右侧发送（发送按钮 32 圆形 `--accent-strong`）

### 4.3 卡片

标准卡片：底 `--surface`、圆角 20、内边距 20、`--e-1`、内部 gap 16。
列表型卡片（账单/设置）：内边距 8，行内边距 12/16，行间 1px `--line` 分隔（末行不画）。

### 4.4 AI 洞察卡（核心差异件）

```
┌─ --accent-wash 底 · 圆角 12–16 · 无阴影 ────────┐
│ ✦ AI 洞察           （11/600 --accent-text）    │
│ 正文 12–13/400 · 行高 1.6 · 色 #7A4E2E          │
│ [可选行动按钮 · h 32 · --r-full]                │
└──────────────────────────────────────────┘
```

**强制约束**：
1. 任何 AI 生成文本必须带 `✦ AI` 标记，禁止裸排
2. AI 结论必须附**可执行下一步**（按钮或链接），禁止只给结论
3. 流式生成中显示三点脉冲 + 「AI 正在思考…」，生成完保留「由 AI 生成，可能有误」的次级说明入口

### 4.5 数据展示

| 组件 | 规格 |
|------|------|
| 进度条 | 高 6，圆角 3，轨道 `--track`，填充 `--accent`→`#FF8A4D` 90° 渐变；超 100% 转 `#D63600` |
| 评分环 | 100×100，环宽 8，底 `--track`，进度 `--accent-strong`，中心数字 28/700 |
| 折旧图 | 柱宽 15、gap 12.5；已发生区间 `--accent`，预测区间 `#FFCDB8` + 虚线分隔 |
| 趋势折线 | 线宽 2，下方 12px 渐变面积；关键点用 6px 实心点 + AI 批注 |
| 「值得指数」徽标 | ≥80 绿 / 60–79 橙 / <60 中性灰，**同时显示分数数字**，不靠颜色单通道 |

### 4.6 导航

**移动端底部药丸标签栏**：62pt 高、圆角 36、`--e-3`、白底 `1px --line`。
4 个 Tab（首页/物品/价值/设置）+ 居中 54pt 渐变 AI 按钮。
选中态：整块填 `--accent-strong`（白字），非选中 `--ink-3` 图标 + `--ink-2` 文字。
进二级页（详情/AI）时标签栏隐藏，用导航栏返回按钮回退。

**桌面端侧边栏**：248px、分组标题 11/500 `--ink-2` 大写间距、选中项 `--accent-soft` 底 + `--accent-text` 文字 + 左侧 3px 强调条。

### 4.7 状态组件（必备）

每个数据视图都必须定义四态：

| 状态 | 表现 |
|------|------|
| 加载 | 骨架屏（圆角 8 的 `--track` 块，1.2s 呼吸），**不用转圈** |
| 空 | 96pt 插画 + 17/600 标题 + 13 说明 + 1 个主 CTA |
| 错误 | 图标 + 一句话原因 + 「重试」主按钮 + 「查看日志」次按钮 |
| 无网络 | 顶部 1 条 44pt 橙色提示条，内容保留缓存数据并标注「离线数据」 |

## 5. 无障碍标准（WCAG 2.1 AA）

| 项 | 要求 | 本系统做法 |
|----|------|-----------|
| 正文对比度 | ≥ 4.5:1 | 已实测，见 §2.1；`#FF4500` 限用于大字号/非文本 |
| 大字对比度 | ≥ 3:1 | Display/H1 用 `--accent` 合规（3.44:1） |
| 非文本对比度 | ≥ 3:1 | 图标、图表、输入框描边均 ≥ 3:1 |
| 触控目标 | ≥ 44×44pt | 列表行 ≥ 56，Chip ≥ 32（用 padding 补足 44） |
| 键盘可达 | 全功能键盘可操作 | 全局 `:focus-visible` 用 `--focus` 环；Skip-to-content 链接 |
| 屏幕阅读器 | 语义化 + ARIA | 金额加 `aria-label`（如「支出 230 元」）；图表配 `role="img"` + 文字摘要 |
| 动态字体 | 支持 200% 缩放不截断 | 全部用相对单位，禁止固定高度 + 溢出隐藏 |
| 动效敏感 | 尊重系统设置 | `@media (prefers-reduced-motion: reduce)` 关闭所有过渡 |
| 颜色单通道 | 禁止 | 异常消费 = 图标 + 文字 + 颜色三重编码 |
| 深色模式 | 完整适配 | Token 全量映射，不新增硬编码色值 |

## 6. 双端映射规则

同一个功能在两端的形态对应关系，开发时按此表落地：

| 模块 | 移动端 | 桌面端 |
|------|--------|--------|
| 总览数据 | 1 张大卡纵向堆叠 | 3 张 KPI 卡 + 8 栏时间线 |
| 账单流 | 无限滚动列表，左滑操作 | 表格 + 行悬停操作，支持排序筛选 |
| 物品库 | 2 列网格 | 4 列网格（≥1440px 5 列），支持列表/网格切换 |
| 物品详情 | 全屏页 + 大 Hero | 右侧 560px 抽屉，图表更大 |
| AI 对话 | 全屏深色面板（从 Tab 中心升起） | 右侧 420px 深色抽屉，可常驻并排 |
| AI 洞察 | 内嵌浅色卡片 | 内嵌卡片 + 侧列「洞察流」 |
| 记账入口 | 底部居中悬浮 AI 按钮 | 顶栏主 CTA + 全局快捷键 `⌘K` |
| 设置 | 分组列表页 | 侧边栏二级导航 + 右侧表单 |

**不变项**（两端必须一致）：Token 值、组件圆角/间距节奏、AI 卡片样式、语义色含义、文案语气。

## 7. 文案语气

| 场景 | 语气 | 示例 |
|------|------|------|
| 记账成功 | 简短确认 | 已记录 ✓ 餐饮 · ¥230 |
| AI 洞察 | 朋友式、不评判 | 这个月咖啡省下来了，比上周少 40% |
| 预警 | 陈述事实 + 给方案 | 餐饮比上月多 18%，主要是周末聚餐。要不要看看替代方案？ |
| 空状态 | 邀请行动 | 还没有物品。拍张照片，AI 帮你估值 |
| 错误 | 说清原因 + 给出口 | 没能连上服务器，数据还在本地。重试 |

用户可在设置中切换 AI 语气（专业 / 轻松 / 严格），**默认轻松**。
